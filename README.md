# Configuração e Gestão de Sistemas (COGSI)

## Project Repository

This repository contains the work developed within the scope of the **Configuração e Gestão de Sistemas (COGSI)** of the **Master's Degree in Cybersecurity and Systems Administration** at ISEP during the 2026/2027 academic year.

The project follows the different course modules, exploring tools and methodologies used throughout the lifecycle of modern applications, from source control and automation to containerization and observability.

## Project Objectives

The objective of this project is to apply DevOps and System Administration concepts and tools, including:

- Source Control Management with Git;
- Build Automation with Gradle;
- Virtualization with Vagrant;
- Configuration Management with Ansible;
- Containerization with Docker;
- Continuous Integration and Delivery with Jenkins;
- Observability with Prometheus, Alertmanager, and Grafana.
